About This Project

An AI-powered skin lesion classification system built for academic research.

🧠 Model Architecture

Built on EfficientNet-B0 pretrained on ImageNet, fine-tuned on a 9-class skin lesion dataset. Uses Test-Time Augmentation (TTA) over 5 passes to stabilize predictions.

📊 Dataset

Trained on a combination of HAM10000 and additional clinical images. Classes include melanoma, BCC, SCC, actinic keratosis, benign keratosis, dermatofibroma, melanocytic nevi, vascular lesions, and normal skin.

🔬 Detectable Conditions

  • Melanoma
  • Basal Cell Carcinoma
  • Squamous Cell Carcinoma
  • Actinic Keratosis
  • Benign Keratosis
  • Dermatofibroma
  • Melanocytic Nevi
  • Vascular Lesion
  • Normal Skin

⚙️ Tech Stack

  • Python 3.10
  • TensorFlow 2.16 + tf_keras
  • EfficientNet-B0
  • OpenCV (image preprocessing)
  • Flask (web framework)
