Overview

This project is a deep learning based web application designed to classify different types of skin lesions using dermoscopic images. The system uses EfficientNetB0 transfer learning architecture along with image preprocessing and test-time augmentation techniques to improve prediction performance.

The application provides:

Multi-class skin lesion classification
Confidence score prediction
Risk-level analysis
Web-based user interface for image upload and prediction

The project was developed for educational and research purposes to demonstrate practical applications of Deep Learning in medical image classification.

Features

✅ Multi-class skin cancer classification
✅ EfficientNetB0 transfer learning
✅ Image preprocessing and augmentation
✅ Risk-level prediction system

Installation

Clone Repository

git clone https://github.com/Muthuworkspace/AI-Powered-Skin-Cancer-Detection-System.git

Move to Project Folder

cd AI-Powered-Skin-Cancer-Detection-System

Create Virtual Environment

Windows

python -m venv venv

venv\Scripts\activate

Linux / Mac

python3 -m venv venv

source venv/bin/activate

Install Dependencies

pip install -r requirements.txt

Run the Application

python app/app.py

Open browser:

http://127.0.0.1:5000
